COMPARISON TO inv11 / hot-offset (tools)
  Same Δ set {1,10,11,12} and same a221o fold.
  Tools encode the **forbid** form: if I@t and I@(t+Δ) would make
  a221o live under the later I, force the partner to 0 (unless the
  later cycle sits on an allowed window below).
  Phase-3 SET text is the **arm** form of the same mechanism: sticky
  SET rises when such a **forbidden** (unsafe) pair occurs.
  → Forcing / CP-SAT: treat unsafe partners as forced 0s (hot-offset).
  → "Allowed" = sticky does **not** arm = safe for the forcer.

ALLOWED NEIGHBOR / LATER WINDOWS (hard — measured)
  Let t0 < t1 with I[t0]=I[t1]=1 and Δ = t1 − t0.

  Criterion: residue is **allowed** iff the two-one pair does **not**
  arm sticky `inv_2_11__A` (dfrtp_2_37.Q). Measured on rows 5 and 8
  (both agree); single-one and all0 controls never arm.

      Δ = 1 or 12 :  t1 ≡ 0 (mod 11)
                     cycles: 0,11,22,33,44,55,66,77,88,99,110
                     (was wrongly listed as ≡10 / or4=0000)

      Δ = 10      :  t1 ≡ 10 (mod 11)
                     cycles: 10,21,32,43,54,65,76,87,98,109,120
                     (was wrongly listed as ≡9 / or4=0101)

      Δ = 11      :  **never** allowed (ungated a221o.B2 path always live)

  Equivalently (forcer / hot-offset form):
    For each forced I=1 at t, and each k ∈ {1,10,11,12}:
      if t+k (or t−k) would form a forbidden pair → force that partner to 0.
    Forbidden = (Δ=11) OR (Δ∈{1,12} and later ̸≡ 0) OR (Δ=10 and later ̸≡ 10).

  Neighboring ones (Δ=1) and ones 10–12 cycles later are therefore
  banned **except** when the later cycle lands on the allowed window
  above (row-boundary wrap for Δ=1/12; later≡10 for Δ=10).

RULE (SET arm — when sticky rises)
  Sticky SET (inv_2_11__A) arms when there exists a **forbidden** pair
  (Δ, t1) as above with I at both ends (a221o live under the later I).
  Then it holds via B1 feedback.
  Spacings outside {1,10,11,12}, or Δ∈{1,10,12} with t1 on the allowed
  window, do **not** arm SET by themselves.
  (Earlier text said SET arms on *allowed* pairs — that inverted the
  measurement. Also: success does **not** require this sticky to arm;
  the forced 22-one solution leaves inv_2_23.A high for the whole run.)
